AI proposes.
An independent check audits.
A human decides.

A human-in-the-loop decision desk for high-stakes eligibility. The AI extracts evidence with citations, a deterministic rules engine checks eligibility, a verifier abstains when evidence is missing or contradictory, and an officer makes the final call — recorded in a tamper-evident log. Nothing is ever auto-denied.

Grounding

Evidence with citations

Every claimed fact is tied back to a verbatim span in a source document and re-checked deterministically.

Deterministic

Rules in plain code

Eligibility rules run as ordinary code and return PASS / FAIL / UNKNOWN. The model never decides the rule.

Abstention

The verifier can refuse

Missing fields, contradictions, or unfound citations force an abstain — the case is escalated to a person.

Accountability

Auditable by design

Each human decision is hash-chained into an append-only ledger with a one-click integrity check.
